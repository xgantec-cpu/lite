# Rapid Response Admin Quick Start

## The case journey

1. **Incoming incidents** — new emergency requests appear here first.
2. **Open the case** — read the message, location, map, media, and current status.
3. **Coordinate** — use notes, in-house chat, files, calls, or a referral to involve the right team.
4. **Update the status** — acknowledge, respond, resolve, or close the case.
5. **Review the record** — completed cases remain in the archive and can be included in reports.

### Simple example

If a request comes from Masaka, it is routed to a responder assigned to Masaka. If police support is required, the responder refers the same case to the correct police station. The case reference, map, communication, and status remain connected.

## What each workspace means

- **Cases by district:** View activity and district-level summaries.
- **Global case map:** See handled cases and selected case locations.
- **In-house chat:** Coordinate with other approved responders.
- **Referral inbox:** Review cases transferred to your account.
- **Cases archive:** Find acted-on cases and public alert history.

Only cases assigned or referred to your account are available to you. Use the sign-out button when leaving a shared computer.
